# Third-party notices

Generated at release by the stack's licence tool (see
[docs/DEPENDENCIES.md](docs/DEPENDENCIES.md)), plus hand-kept entries for
anything a lockfile cannot see: vendored fonts, icons, colour profiles,
binary SDKs. Regenerate before every release; do not hand-edit the
generated section.

No third-party components are shipped yet.

Hand-kept entry format:

```
## <component> <version> (<SPDX licence>)

Source: <URL>
Files: <paths>
SHA-256: <hash of the vendored file>

<full licence text, verbatim, including copyright lines>
```

Keep notices for MIT, ISC, BSD, Apache-2.0 (plus any NOTICE file the
component ships), MPL-2.0 and OFL-1.1 components.
